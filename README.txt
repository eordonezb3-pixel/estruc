PROYECTO ESTUDIANTES

Sistema CRUD de estudiantes desarrollado en Python siguiendo la arquitectura
MVC indicada en la guía.

ESTRUCTURA

proyecto_estudiantes/
├── main.py
├── views.py
├── models.py
├── shared/
│   ├── __init__.py
│   ├── herramientas.py
│   └── json_manager.py
└── data/
    └── estudiantes.json

EJECUCIÓN

1. Abrir esta carpeta en Visual Studio Code.
2. Abrir la terminal.
3. Ejecutar:

   python main.py

No requiere instalar librerías externas.
